# Bitcoin Trading System - Claude Code Resume Context

## System Overview
This is a sophisticated adaptive cryptocurrency trading system that maintains 100% position allocation - either fully in BTC (LONG) or fully in USD (SHORT). There is no neutral position.

## Key System Understanding
- **BTC amount in commands = LONG position** (holding Bitcoin)
- **USD amount in commands = SHORT position** (holding dollars)
- Example: `auto_trade 1.5btc long` vs `auto_trade 167500usd short`

## How to Resume the System
1. Exit: `quit`
2. Restart: `python src/tdr.py`
3. Resume position: `resume_auto_trade 165578.22usd short 106950`
4. Enable commands: `enable_commands`
5. Verify: `status`

## Key Adaptive Strategy Logic
The system uses three strategies based on market regime:
- **TRENDING**: MA crossover strategy for directional markets
- **RANGING**: Mean reversion using RSI + Bollinger Bands
- **VOLATILE**: Breakout strategy using MACD + volume

Regime detection based on:
- Whipsaw ratio (MA crossover failures)
- Trend strength
- Price volatility
- Range-bound score

## Important Trading Rules
- Always 100% invested (no cash position)
- Max 5 trades per day
- Minimum 10 minutes between trades
- Requires 2 bar confirmation for signals
- Emergency exit at $2,000 loss

## Known Issues to Watch
1. Position tracking can lose sync after crashes - use `resume_auto_trade` to fix
2. The system logs extensively to diagnostic files - check these for debugging
3. WebSocket can disconnect during low volume - auto-reconnects after 2 minutes
