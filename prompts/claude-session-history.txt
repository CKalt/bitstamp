## Key Design Decisions
1. Client holds all config files (best_strategy.json)
2. Server is stateless until initialized by client
3. Claude creates JSON commands locally, client forwards to server
4. All logs stay on server, accessible via REST API
5. Position persistence via resume-auto-trade.json

## REST API Endpoints
- POST /api/initialize - Client sends config
- POST /api/command - Execute any shell command
- GET /api/status - System and position info
- GET /api/logs - View server logs
- GET /api/diagnostics - Trading diagnostics
- GET /api/trades - Trade history
